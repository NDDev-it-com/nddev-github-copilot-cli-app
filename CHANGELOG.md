# Changelog

All notable changes to `nddev-github-copilot-cli-app` are documented here.

## [0.1.0] - 2026-07-26

- Initial target-explicit GitHub Copilot CLI setup manager.
- `safe`, `balanced`, and `full-auto` setup variants for the current CLI
  launch flags, settings, permissions, and instructions surfaces.
- Default-on local native `nddev-builder` plugin projection with skills, agents,
  hooks, and user-file projections.
- Public contract validator and shared public CI callers.
